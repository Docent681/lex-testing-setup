# lex-testing-setup - набор инструментов для тестирования lex-программ

 [Требования](#Требования) • [Установка](#Установка) • [Использование](#Использование)
 
 </div>
 
 Данный проект изначально был создан для тестирования университетских **lex-программ**. В первую очередь будет полезно студентам, которым необходимо писать и тестировать lex-программы.
 
## Требования
- Дистрибутив Linux (протестировано на [Linux Mint](https://linuxmint.com/))
- Make
- Git

## Установка
Убедитесь, что у вас установлены все необходимые программы. Далее склонируйте данный репозиторий следующей командой:

```shell 
git clone https://github.com/Docent681/lex-testing-setup.git
```

## Использование
Перед использованием проекта создайте в корне проекта файл с названием `dir_path`, запишите в него **полный путь** к вашему экземпляру проекта.

> [!IMPORTANT]
> Представленные в проекте скрипты будут запускаться корректно только из директорий, в которых лежит файл dir_path. Либо запускайте все скрипты из корня проекта, либо создайте несколько копий dir_path

Коды lex-программ должны хранится в директории **src** под названиями `listing<номер программы>`. С проектом идут примеры кодов, при ненадобности их можно удалить.
Для компиляции lex-программ исполните в корне проекта команду:

``` shell
make
```

Тестирование запускается следующей командой:

``` shell
./tests/run.sh <номер программы>
```

Скрипт ищет в каталог **tests/task<номер программы>/**, в этом каталоге должны лежать тройки файлов:
- in<номер теста>.txt
- out<номер теста>Exp.txt
- out<номер теста>Irl.txt

содержимое In-файлов подается на входной поток, результат работы программы подается в outIrl файл и сравнивается в содержимым outExp файла

> [!IMPORTANT]
> In и Exp файлы должны быть заполнены вами самостоятельно в соответсвие с вашим тестированием

Вместо того, чтобы вручную создавать пустые тройки файлов, можно прогнать следующий скрипт:

``` shell
./generate_files.sh <количество троек>
```

Каждый имеющийся **task/** будет дополнен заданным количеством пустых троек

Для отчетности, если вы не хотите вручную задавать содержимое Exp файлов и уверены в правильности работы lex-программ, можно прогнать скрипт, который скопирует содержимое Irl файлом в Exp:

``` shell
./copy_files.sh
```

> [!WARNING]
> Данный скрипт не будет изменять содержимое уже заполненных Exp файлов
